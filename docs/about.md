# Zensical とは

Zensical は、Markdown で書いた文書から、ドキュメントサイトを生成するツール(静的サイトジェネレーター)です。
Material for MkDocs を開発してきたチームが作っています。

## 何ができるか

- **Markdown からサイトを作る。** `docs/` に Markdown を置くと、HTML のサイトとして出力されます。
- **見やすいサイトが最初から手に入る。** スマートフォンを含む、さまざまな画面幅に対応したデザインです。
- **検索が使える。** サイト内の全文検索が組み込まれています。
- **多言語に対応している。** 60 以上の言語に対応しています。
- **設定は 1 つのファイル。** `zensical.toml` に、サイト名、ナビゲーション、テーマなどをまとめて書きます。
- **公開が簡単。** 出力されたサイトは静的なファイルなので、GitHub Pages などにそのまま置けます。

## 技術と位置づけ

- 処理の中心は Rust で書かれ、拡張のしやすさのために Python も組み合わせています。
- **MkDocs の後継**として設計され、MkDocs のプロジェクトとの互換性も保たれています。
- ライセンスは **MIT** で、無料で使えます。

## 向いている用途と向かないこと

### 向いている用途

- 製品やライブラリのドキュメント、ユーザーマニュアル
- 開発者向けの設計書、仕様書、手順書
- 社内のナレッジベースなど、README に収まらない規模の資料

複数ページで構成され、目次や検索が必要な文書に向いています。
Markdown なので、Git で変更履歴を管理し、レビューもできます。

### 向かないこと

- Word や Excel などの形式が必須の文書(顧客への提出用など、書式が決まっているもの)
- 印刷を前提とした、細かいレイアウトの制御が必要な文書
- Markdown や Git に慣れていない人が、頻繁に編集する文書

## 基本のコマンド

| コマンド | 内容 |
|---|---|
| `zensical new` | 新しいプロジェクトを作成する |
| `zensical serve` | プレビュー用のサーバーを起動する |
| `zensical build` | サイトを出力する |

実際の手順は、[インストール](install.md)と[GitHub への公開](publish.md)にまとめています。

## 関連するもの

### Zensical Studio

Zensical や MkDocs のプロジェクトを書きやすくする、VS Code 向けの拡張機能です。
補完、検証、リンクの自動更新などが使えます。Zensical 本体とは別のソフトで、**使わなくてもサイトは作れます**。

- 無料版(Studio)と、有料版(Pro、Team)があります。
- Zensical 本体は MIT ライセンスですが、Studio は別の使用許諾契約(EULA)です。
  EULA が適用されるのは Studio というソフトで、作成したサイトの内容には適用されません。

!!! note "Studio の利用条件"

    公開ベータ中の条件と、それ以降の条件は異なります。会社の業務で使う場合は、
    使う時点の最新の EULA と料金を、[Zensical Studio](https://zensical.org/studio/) で確認してください。
