# Zensical とは

Markdown で書いた文書から、ドキュメントサイトを作るツール(静的サイトジェネレーター)です。
Material for MkDocs を開発してきたチームが作っています。

## 特徴

- **Markdown から HTML のサイトを作る。** `docs/` に置いた Markdown が、そのままサイトになります。
- **見やすいデザインが最初から入っている。** スマートフォンにも対応し、全文検索も使えます。
- **設定は 1 ファイル。** `zensical.toml` にまとめて書きます。
- **公開が簡単。** 出力は静的なファイルなので、GitHub Pages などにそのまま置けます。
- **MIT ライセンスで無料。** MkDocs 1.x の置き換えとして、互換性も保たれています。

## 向き不向き

**向いているもの**

- 製品やライブラリのドキュメント、ユーザーマニュアル
- 設計書、仕様書、手順書
- 社内のナレッジベースなど、複数ページの資料

Markdown なので、Git で変更履歴を管理し、レビューもできます。

**向かないもの**

- Word や Excel の形式が必須の文書
- 印刷前提で、細かいレイアウトが必要な文書
- Markdown や Git に慣れていない人が頻繁に編集する文書

## 基本のコマンド

| コマンド | 内容 |
|---|---|
| `zensical new` | 新しいプロジェクトを作成する |
| `zensical serve` | プレビュー用のサーバーを起動する |
| `zensical build` | サイトを出力する |

実際の手順は、[インストール](install.md)と[GitHub への公開](publish.md)を参照してください。

## 関連情報

??? info "Zensical Studio(VS Code 向けの拡張機能)"

    Zensical のプロジェクトを書きやすくする拡張機能です。補完、検証、リンクの自動更新などが使えます。
    本体とは別のソフトで、**使わなくてもサイトは作れます**。

    - 無料版(Studio)と、有料版(Pro、Team)があります。
    - Zensical 本体は MIT ライセンスですが、Studio は別の使用許諾契約(EULA)です。
      EULA が適用されるのは Studio というソフトで、作成したサイトの内容には適用されません。
    - 公開ベータ中と、それ以降で条件が異なります。会社の業務で使う場合は、
      [Zensical Studio](https://zensical.org/studio/) で最新の EULA と料金を確認してください。
